# Overview
This project is a continuation of a previous frontend To-Do List Application. For this version I wanted to build and practice my full-stack development skills. The app allows the user to manage tasks or to-do list items, switch between list and card views, and track productivity stats.

The purpose of this application is to get more hands-on experience building web applications that connect front-end pages to Node.js/Express back-end APIs.

[Software Demo Video](https://youtu.be/4ickIbTb8kw)

# Web Pages
- Home Page (index.html)
Users can view this page and add, edit, complete, and delete tasks. These tasks are displayed dynamically in list or card view, and users can toggle between light and dark mode.
- About Page (about.html)
An about page that shares the purpose of the app and its functionality.

- Stats page (stats.html)
This page displays live statistics from the server (total tasks, completed tasks, and upcoming tasks). The tasks are displayed dinamically.
